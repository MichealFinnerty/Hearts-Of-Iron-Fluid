Bebas Neue, Oswald, Libre Baskerville and IBM Plex Mono, self-hosted so the game works offline and on GitHub Pages.
All four are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Files come from the Fontsource npm packages.
Roles: Bebas Neue = country names on the map, Oswald = headings and buttons, Libre Baskerville = dates, descriptions, city and province names, IBM Plex Mono = statistics and data.
